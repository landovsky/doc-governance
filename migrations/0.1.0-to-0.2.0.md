# Migration 0.1.0 → 0.2.0

Bring a repo pinned at `model_version: 0.1.0` up to `0.2.0`. All steps are **manual**; the
per-hop codemod is **DEFERRED — TODO (tooling, later)**. See
[`../guides/MIGRATING.md`](../guides/MIGRATING.md) for the surrounding workflow.

## What changed (the v0.1 → v0.2 deltas)

1. **+ derived citeability `tier` (`canonical | source | archive`)** — the headline change.
   v0.1 had no tier; it carried a **derived** `trust: current | historical` binary (also
   computed, never hand-set), which collapsed cite-able ADRs and never-cite transcripts under
   one `immutable` class. **`tier` is likewise derived — it replaces `trust` with a three-value
   axis that can express `source` (the case the binary could not).**
2. **+ `owner` and `updated` required in the core.** The steward loop needs an assignee
   (`owner`), and content-last-changed (`updated`) is distinct from freshness-checked
   (`last_verified`). v0.1 repos often carried `modified_at` — **rename `modified_at` → `updated`.**
3. **+ `ships:` on every transient** — the `#PR`/`#issue` that retires it, so resolution is
   derived from the merge rather than a hand-set status that drifts.
4. **+ `event_date` on raw/source types** (`transcript`, `audit`, `research`, `experiment`) — the
   moment the evidence was captured; relevance decays from it.
5. **ADR and transcript now differ by `tier`, not by class.** Both stay `class: immutable`;
   the ADR derives `tier: canonical` (cite it), the transcript is `raw: true` and derives
   `tier: source` (never cite). No class move — the split is expressed through `tier`.
6. **+ `immutable(ADR) → living(reference)` propagation edge** + a CI check that a merged ADR's
   `covers[]` docs were touched — so a ratified decision propagates into the durable reference
   docs instead of silently un-propagating.
7. **+ `covers[]`-existence check** — every path a living doc lists in `covers[]` must exist in
   THIS repo (not merely be drift-checked), which also kills cross-repo contamination in one rule.

**Decision D-1 (resolved):** Kept 3 classes + a derived `tier`, rather than adding a 4th `source` class.

## Per-file manual steps (v0.1 front matter → v0.2)

Do these to **every governed `.md`** in the repo:

1. **Replace `trust:` with derived `tier:`.** Delete the `trust:` key. Add `tier:`, writing the
   value that *derives* from the doc's class/type (do not choose freely):
   - immutable ADR / living reference-or-runbook, not stale, not superseded → `tier: canonical`
     (v0.1 `trust: current`).
   - raw type (`raw: true` in `_types.yml`: transcript/audit/research/experiment) → `tier: source`.
   - terminal (superseded immutable · resolved-&-unpromoted transient · retired living) →
     `tier: archive` (v0.1 `trust: historical`).
2. **Ensure `owner:` exists.** Add `owner: "@…"` if missing.
3. **Rename `modified_at:` → `updated:`.** If neither exists, add `updated:` = the date content
   last changed.
4. **On every `transient` doc, add `ships:`** = the `#PR`/`#issue` that retires it. If it already
   shipped/was killed, set the terminal `status:` and let it derive to `tier: archive`.
5. **On every raw/source doc, add `event_date:`** (the capture date). Set `source_of:` if it has
   been distilled into a downstream doc.
6. **Confirm the immutable pair.** ADRs and transcripts stay `class: immutable`; verify the
   transcript's type is `raw: true` in `docs/_types.yml` so it derives `source` (not `canonical`).
7. **Living docs unchanged in shape** but now: `covers[]` + `last_verified` still required, and a
   `last_verified` with no `covers[]` is **rejected** — fix any such orphan now.

### Before / after

```yaml
# v0.1                              # v0.2
class: immutable                    class: immutable
type: transcript                    type: transcript
trust: historical          →        tier: source          # derived (raw ⇒ source)
modified_at: 2026-06-01    →        updated: 2026-06-01
                                    event_date: 2026-06-01 # NEW (raw type)
owner: "@landovsky"                 owner: "@landovsky"    # ensure present
```

```yaml
# v0.1 transient                    # v0.2 transient
class: transient                    class: transient
type: spec                          type: spec
trust: current             →        tier: canonical        # derived (active, not terminal)
                                    ships: "#412"           # NEW — required on transient
modified_at: 2026-08-01    →        updated: 2026-08-01
```

## Verify

- No `trust:` key remains anywhere; every doc has a `tier:` that matches its derived value.
- Every doc has `owner` and `updated`; no `modified_at:` remains.
- Every transient has `ships:`; every raw/source doc has `event_date:`.
- No `last_verified` without `covers[]`.
